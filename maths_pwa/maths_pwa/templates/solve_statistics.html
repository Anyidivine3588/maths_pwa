Ungrouped Data and Frequency Tables

Raw data: type the numbers, e.g. 3, 7, 8, 5, 12, 14, 21, 13, 18, 7 and leave the frequency box empty.
Frequency table: type the values (x) in the first box and their frequencies (f) in the second, in the same order.

Grouped Data

Type the class intervals separated by commas, e.g. 1-10, 11-20, 21-30, 31-40, 41-50, and the frequencies in the same order. Classes like 0-10, 10-20, 20-30 also work. Gives the table with boundaries, mid-points and cumulative frequency.
