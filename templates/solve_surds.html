Simplify a Surd

e.g. √50 → 5√2, √72, √(18/25), 3√48, ∛54, or √12 × √6. Shows the prime factors and the perfect square that comes out. No √ key? Type sqrt(50) instead.

Surd Arithmetic

e.g. √12 + √27 − √3, 2√3 × 3√6, (2+√3)(4−√3), (√5+√2)², (3+√2)(3−√2), √8 ÷ √2, √(7+4√3). Every surd is simplified first, brackets are expanded term by term, then like surds are collected.

Rationalise the Denominator

Single surd (1/√2, 12/√3, 5/(2√5)) or a binomial denominator using the conjugate (1/(2+√3), (√5+√2)/(√5−√2), 3/(√7−2)). Gives the answer in the form p + q√r and the value when √2 = 1.414, √3 = 1.732 etc. are given.

Solve an Equation with a Surd

e.g. √(x+5) − √(x−4) = 1, √(2x+1) = x − 1, x − 5√x + 6 = 0, √x + √(x+7) = 7. Isolates a root, squares both sides (repeating if needed), then checks every candidate in the original equation — squaring can introduce false answers, so rejected ones are shown. Type sqrt(...) if you can't find the √ symbol.
