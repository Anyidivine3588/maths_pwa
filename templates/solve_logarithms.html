Evaluate a Logarithm

e.g. log_2(8), log_8(4), log_(1/2)(4), log(0.001), ln(e^3), or a sum like log_2(12) + log_2(4/3). A bare "log" means base 10.

Change of Base

log_b(a) = log_c(a) / log_c(b)

Laws of Logarithms

Expands or combines using log(ab)=log(a)+log(b), log(a/b)=log(a)-log(b), log(a^n)=n.log(a)

Solve a Logarithmic Equation

e.g. log_2(x) = 5, or log(x-1) + log(x+3) = 2, or log_2(x-2) + log_2(x+2) = 2. A bare "log" means base 10 (the WAEC convention); use log_b(...) for another base. Solved algebraically by combining the logs and converting to exponential form -- no calculator or log tables needed.

Using Log Tables (base 10, no calculator)

This is the four-figure-table method exam officers expect when calculators aren't allowed: write the number in standard form, split into characteristic and mantissa, then combine them.

Antilog

Given a logarithm, find the original number. You can type a decimal (2.7686), a negative (-2.4559) or bar form (type bar3.5441 for 3̄.5441).

Calculate with Log Tables

Multiply, divide, find powers and roots the exam way: look up each log, add / subtract / multiply / divide the logs, then take the antilog. e.g. 587 * 0.0342, 45.6 / 2.37, 2.35^3, sqrt(587), 587^(1/3), (2.5 * 3.4) / 1.7
