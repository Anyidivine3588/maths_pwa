Table of Values

Type the function. It can have x powers and trigonometry: x^2 - 2x - 3, sin x, sin^2 x, 3sin x - 4cos^3 x, 2sin(3x + 30), tan x, 1/x, 2^x. You may also write it as "y = …". The table shows one column for each term, so you can see how y is built up. The Plot tab uses this same function, unless you choose a different one there.

Next: open the Plot Function(s) tab to draw this function.

Plot Function(s)

By default the graph uses the same function as your table, and can mark the table's points on the curve. If you need a different function, untick the box and type it. To see where two graphs cross, put a second function in g(x): the crossing points are marked and written below the graph.
